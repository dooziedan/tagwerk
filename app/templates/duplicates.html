How Tagwerk finds copies
  • Identical file: the same size and the very same content.
  • Same MusicBrainz recording: the same recording ID, trusted only when every track with that ID has the same artist and title (some taggers copy one ID onto a whole EP), and about the same length.
  • Same artist and title: the first artist and the full title, mix name included (an Extended Mix is not the Radio Edit), with lengths within 3 seconds. Spelling is evened out: case, accents, “&”/“and”, “feat.” parts.
